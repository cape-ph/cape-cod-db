# cape-cod-db Context Notes

This directory contains project context documentation for the cape-cod-db project.

## Purpose

These notes help agents and developers quickly understand the project structure, architecture, and current state without re-reading all code.

## Structure

- **00-overview.md**: High-level project description, purpose, and architecture
- **01-models.md**: Database models and ORM patterns
- **02-migrations.md**: Alembic migration system and workflow
- **03-cli-tools.md**: Command-line scripts and their usage
- **04-database-connection.md**: Database connection setup and configuration
- **05-development.md**: Development workflow, testing, and conventions

## Maintenance

When making changes to code:
1. Update relevant context notes in the same session
2. Create new note files if introducing new subsystems
3. Keep notes synchronized with code state
